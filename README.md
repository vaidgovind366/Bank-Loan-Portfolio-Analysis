# Bank Loan Portfolio Analysis

## 📊 Project Overview

This project focuses on analyzing bank loan portfolio data to understand loan performance, customer behavior, risk patterns, and overall lending trends.

The project uses **Tableau for interactive data visualization** and **SQL for data analysis and business insights**.

The dashboard helps users monitor key loan KPIs, identify Good and Bad Loans, analyze loan status, and explore trends across states, purposes, employment length, home ownership, loan terms, and other business dimensions.

---

## 🎯 Project Objectives

- Analyze overall loan application and funding performance
- Monitor Good Loan vs Bad Loan performance
- Track monthly and Month-over-Month (MoM) loan trends
- Understand loan status distribution
- Analyze loan portfolio by state
- Identify major loan purposes
- Analyze employment length and home ownership patterns
- Understand loan term and loan grade distribution
- Provide business-focused insights through interactive dashboards
